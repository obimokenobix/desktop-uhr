# Desktop-Uhr

Wochentag, Uhrzeit und Datum transparent direkt auf dem Windows-Desktop – wie mit Rainmeter, nur ohne Rainmeter.

**Download & Anleitung:** https://obimokenobix.github.io/desktop-uhr/

## Installieren

1. [`DesktopUhr.zip`](DesktopUhr.zip) herunterladen und entpacken (z. B. nach *Dokumente*).
2. `Desktop-Uhr starten.cmd` doppelklicken.
3. Rechtsklick auf die Uhr öffnet alle Einstellungen.

## Funktionen

- liegt auf dem Desktop hinter den Fenstern (oder normal / immer im Vordergrund)
- Bearbeiten-Modus: jeden Buchstaben und jede Ziffer einzeln verschieben oder entfernen
- 4 Größen, 6 Farben, Deckkraft, Ausrichtung, Schatten, Sekunden, Wochentag
- merkt sich Position und Einstellungen, optional Autostart mit Windows

Läuft auf Windows 10 und 11 ohne zusätzliche Installation (Windows PowerShell + .NET Framework sind bereits enthalten).

## Quellcode

Der C#-Code liegt in [`quellcode/`](quellcode/) und ist im Skript `DesktopUhr.ps1` (in der ZIP-Datei) eingebettet.
